Entry for the make.fun bounty "The Word You'd Delete From the Dictionary".

The word:

> queue

`main.py` writes that one word to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Why this word: five letters, and only one of them is pronounced — the other four are silent freeloaders standing in line behind it, doing nothing, for centuries. Erase the word and four letters finally lose their jobs. The queue moves at last.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
